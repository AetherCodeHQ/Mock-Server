# Mock-Server

Dynamic mock server

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Mock-Server.git
cd Mock-Server
go build -o mock-server .
```

## Usage

```bash
.mock-server .
.mock-server --path ./src
```
